■ 基本的な使い方（Cable Generator）

1. Hierarchy で右クリック → `Cable Generator > Create Cable`
2. 生成された `Cable` オブジェクトを選択
3. Project ウィンドウで断面プロファイルを作成（`Create > Cable Generator > ...`）
4. 作成したプロファイルを `断面プロファイル` 欄へドラッグ＆ドロップ
5. Inspector で分割数や UV タイリングを調整、Scene でノット（制御点）を編集
6. 完成したら Inspector の「メッシュを保存 (.asset)」で Bake（保存）

■ 調整項目（最小限の一覧）

【断面プロファイル】
- 複数種類のプロファイルを提供（Heavy Duty / Flat / Parallel / Bundled / Clustered）
- 各プロファイルで半径・幅・厚み・セグメント数・本数などのパラメータを調整
- Clustered 等は乱数シードやジッターで配置バリエーションを制御

【Inspector（ケーブル本体）】
- 分割数（スプライン方向のメッシュ解像度）
- UV タイリング（テクスチャの繰り返し密度）
- メッシュ再生成ボタン（プロファイル変更後の反映）

【Scene ビュー / カーブ操作】
- ノット（制御点）の移動・追加・削除
- タンジェントハンドルで曲率を調整
- 制約モード：Mirror / Continuous / Broken（ハンドル挙動の切替）
- プレビューラインとハンドルで直感的に調整可能

【ノットアタッチメント】
- ノットにオブジェクトをアタッチ可能（コネクタ等の配置）
- 位置・回転・スケールのオフセットを Inspector で調整

【メッシュ保存（Bake）】
- 保存先フォルダ指定（デフォルト: `Assets/dennokoworks/CableGenerator/BakedMesh/`）
- ファイル名: `{オブジェクト名}_cable.asset`（上書き確認あり）
- 保存後は静的メッシュアセットとして利用可能

【操作性・補助】
- Undo/Redo（Ctrl+Z / Ctrl+Y）対応
- エディタ上のツールチップで簡易説明を表示すると親切

【トラブルシューティング（簡易）】
- メッシュが表示されない: `断面プロファイル` が未設定、またはノットが2点未満
- カクカク表示: 分割数や断面の `Segments` を上げる
- テクスチャが引き伸ばされる: UV タイリングを大きくする
- パフォーマンス: 分割数／断面のセグメントを下げる

---
（備考）
- ワークフローは断面プロファイルを中心に、スプライン編集 → パラメータ調整 → Bake(オプション) の順が基本です。
- UI は主要項目（断面プロファイル、分割数、UVタイリング、保存先）を目立たせてください。
